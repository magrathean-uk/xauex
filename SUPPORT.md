# Support

Start with the guide for the problem:

- [Development](docs/DEVELOPMENT.md): dependencies, tests and command limits.
- [Host rebuild](docs/REBUILD.md): environment and systemd installation.
- [Operations](ops/RUNBOOK.md): status, command state, logs and stopping the demo runtime.
- [DSA sidecar](docs/DSA_SIDECAR.md): optional shadow evidence.

Check the repository's [issue tracker](https://github.com/magrathean-uk/xauex/issues) for existing reports. If issue creation is available to your account, use it for reproducible bugs or documentation corrections. Public issue creation may be restricted. Include the commit, relevant component, reproduction steps, expected and observed behavior, and checks already performed. Use small, redacted excerpts rather than full runtime files. Do not post broker identifiers, balances, positions, credentials, private network addresses or provider payloads.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md). A repository checkout cannot establish the health of a deployed service; check the target host using the runbook. No support response time or release-support schedule is promised here.
